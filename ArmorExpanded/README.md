# Armor Expanded

Adds 15 rare named armor pieces in the same style as the base game, one for each vanilla armor set. Each piece is built on its vanilla piece and is better than it at the same quality: +20% armor rating, +50% durability, the vanilla piece's own bonus, and a signature ability.

Every named piece counts toward its set's full set bonus, so you can wear one with the rest of its set. Wearing named pieces from different sets means giving up set bonuses.

They can only be looted or bought, not crafted. When worn they look like the vanilla piece; the icon is recolored.

Adds new icons so has to be installed on server and client. `ArmorExpanded-SERVERSIDE` is the server-only version: it uses tinted vanilla icons, so players don't need to install anything.

## Where to find them

Chance per container opened that it holds one of the pieces:

| Container | Chance |
|---|---|
| Large hardened chest (T5) | 5% |
| Hardened chest (T4) | 4% |
| Locked iron chest, buried treasure, boss zombie loot bags | 2% |
| Wall and picture safes, hidden stashes, strong zombie loot bags | 1% |
| Zombie loot bags | 0.5% |

Traders can stock them from trader stage 50: a typical trader has about a 5% chance per restock to have one (Joel, who sells armor, about 7%). Tier 4-6 trader quests have about a 1 in 20 chance to offer one as a reward choice.

The chances are set by the `DementiveArmorRares` templates at the top of `Config/loot.xml` and `TRADER_PROB` in the generator.

## Multiplayer

Everything works in co-op and on dedicated servers. Sunday Best heals party members (and allies) within 15 meters of the wearer.

## Generating the mod

`Config` and the icons are generated by `Scripts/ArmorExpanded/gen_armor.py` in the repository. Edit the `PIECES` table there and rerun it:

```
python Scripts\ArmorExpanded\gen_armor.py <game dir> ArmorExpanded ArmorExpanded-SERVERSIDE
```
