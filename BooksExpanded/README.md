# Books Expanded

This mod adds 40+ rare books in the same style as the base game. Special skill magazines give 2 crafting skill levels instead of 1, and special perk books unlock 2 perks in their series instead of 1. All books use their own icons and are found in loot and at traders.

Adds new textures so has to be installed on server and client.
