# Ammo Expanded

Adds 15 special ammo types for the vanilla guns, bows and crossbows, in the same style as the base game. Each one shows up in the gun's ammo wheel next to the vanilla ammo.

Each ammo type is unlocked by its own schematic, found in loot alongside the vanilla mod schematics and sold by traders. They are crafted at the workbench (arrows and bolts in your backpack) and cost a bit more than the AP round of their caliber. Loose rounds also turn up in ammo loot and trader stock, rarer than HP and AP rounds.

Adds new icons so has to be installed on server and client. `AmmoExpanded-SERVERSIDE` is the server-only version: it uses tinted vanilla icons, so players don't need to install anything.

## Ammo

| Ammo | Fits | Damage | Effect |
|---|---|---|---|
| 9mm Incendiary | pistols, SMG | 30 (Ball 32) | 15% chance to set the target on fire |
| .44 Magnum Incendiary | magnum, Desert Vulture | 66 (Ball 70) | 35% chance to set the target on fire |
| 7.62mm Incendiary | rifles, machine guns | 44 (Ball 47) | 25% chance to set the target on fire |
| 9mm Frangible | pistols, SMG | 36 | 15% chance to cause bleeding. Armor stops twice as much. Half block damage |
| .44 Magnum Frangible | magnum, Desert Vulture | 80 | 35% chance to cause bleeding. Same trade-off |
| 7.62mm Frangible | rifles, machine guns | 54 | 25% chance to cause bleeding. Same trade-off |
| 7.62mm Match Grade | rifles, machine guns | 52 | +50% headshot damage. 30% tighter spread when aiming. Doesn't pass through targets |
| .44 Magnum Explosive Tip | magnum, Desert Vulture | 60 | Every hit sets off a small blast: 50 damage within 2 meters, including you |
| Dragon's Breath Shell | shotguns | 8 per pellet, 7 m | Sets targets on fire |
| Flechette Shell | shotguns | 6 per dart, 16 darts, 14 m | Each dart that hits has a 10% chance to cause bleeding |
| Bean Bag Round | shotguns | 40, single, 15 m | 50% chance to knock the target down |
| Barbed Broadhead Arrow | bows | 36 (Iron 38) | Always causes bleeding |
| Barbed Crossbow Bolt | crossbows | 56 (Iron 59) | Always causes bleeding |
| Blunt Arrow | bows | 30 | 40% chance to knock the target down |
| Blunt Crossbow Bolt | crossbows | 45 | 50% chance to knock the target down |

Fire is the vanilla flaming arrow burn, so the fire perks apply and burns don't stack. Bleeding and knockdowns are the vanilla effects too.

Incendiary, frangible, bean bag, barbed and blunt ammo show up at the same trader stage as HP rounds and steel arrows; match grade, explosive tip, dragon's breath and flechette at the AP tier.

## Guns from other mods

The new ammo is added to every gun whose ammo list is the vanilla list for its caliber, so guns from other mods that inherit their ammo from a vanilla gun get it too. A gun that writes its own ammo list only gets it if it is loaded before this mod (mods load in alphabetical folder order).

## Multiplayer

Everything works in co-op and on dedicated servers. The explosive tip's blast is set off by the server, so it works for every player.

## Generating the mod

`Config` and the icons are generated by `Scripts/AmmoExpanded/gen_ammo.py` in the repository. Edit the `AMMO` table there and rerun it:

```
python Scripts\AmmoExpanded\gen_ammo.py <game dir> AmmoExpanded AmmoExpanded-SERVERSIDE
```
